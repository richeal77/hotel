# 住客小程序运行配置

用微信开发者工具打开本目录。`project.config.json` 已使用项目 AppID `wxe5d704e735725aba`，请先在微信公众平台核对它属于目标小程序；真实 AppSecret 只放后端，不能写入此目录。

## 三种模式

在「我的 > 验收接口设置」中选择：

- `local-demo`：明确开启后才使用本地演示数据和固定验证码 `666666`，不请求服务器。
- `HTTP 接口（验收）`：使用独立保存的 HTTP API 地址，可填 `http://电脑局域网IP:8080/api/v1`。用于本地联调，不使用本地数据回退。
- `真实微信接口`：先保存独立的 `https://实际域名/api/v1`，再开启开关。执行 `wx.login`、`getPhoneNumber`、`/auth/wx-login` 和 `/auth/wx-bind-phone`，不会发送固定验证码或使用演示 token。请求失败直接报错。

真实模式的 API 地址不能是 IP 或 localhost。当前仓库没有已确认的正式 API 域名，因此不会内置猜测地址。填入域名后，还需在微信公众平台为该 AppID 配置对应的 `request` 合法域名（只填 `https://实际域名`，不带路径），并确认 HTTPS 证书、后端部署和微信登录服务端密钥。真机上不应通过关闭合法域名校验完成验收。

在微信公众平台完善小程序隐私保护指引，声明手机号及订单联系人等实际用途。入会页可打开微信原生隐私指引，并在用户同意后调用微信手机号授权。正式发布前，还要确认小程序主体、认证和手机号能力可用；这些状态不能仅由代码证明。

执行 `pnpm --dir apps/miniapp test` 验证本地逻辑。真实微信登录、手机号授权和合法域名仍需使用目标小程序的体验版在真机验收。
